# reading —— 眼：怎么看图

## 先看四角，再看中间

游戏 UI 的固定位置有固定含义，四角信息密度最高：

| 位置 | 通常是什么 |
| --- | --- |
| 左上 | 血量 / 状态 / 当前任务名 |
| 右上 | 小地图 / 轮次 / 队伍 |
| 左下 | 聊天 / 操作提示 |
| 右下 | 技能 / 道具 / 血量 |
| 中间偏下 | 字幕、对话框 |

**先认位置，再认内容。** 同一款游戏里这些位置基本不变。

## 认界面的方法

1. 找**一个不会变的东西**做锚点（标题字、某个图标的位置）
2. 用 `game_shot` 只拍那一小块（`region`），`scale` 拉到 0.8–1 读字
3. 记住"这个界面长这样"，写进该游戏的 `screens.md`

## 宫格怎么读

- 左上角是**序号 + 相对时间**（`1 0.1s` = 第 1 格，动作开始后 0.1 秒）
- 一格变化 = 这一秒发生了什么；**格子之间没变化 = 那几秒是空的**
- 想看清某一格 → 用 `game_shot` 在你关心的区域重拍一张大图

## 判断"变了没有"

不要靠感觉，靠可比较的东西：

- 同一个区域的文字变了吗（弹窗、按钮、计数）
- 血条/进度条位置变了吗
- 主角在屏幕上的位置变了吗

## 看不清的时候

| 现象 | 处理 |
| --- | --- |
| 字太小 | `scale` 调大，或直接用 `region` 只拍那一块 |
| 图全黑 | 游戏是独占全屏 → 让人改成无边框窗口 |
| 一片糊 | 采样帧赶上了转场/闪白，换 `every` 再拍一次 |
| 不知道该看哪 | 先拍整窗 0.4，再挑区域放大 |
