# stages —— 具体关卡

一个文件一关，文件名用关卡名（`combat-2.md`、`combat-3.md`）。

## 模板（照这个写，别自由发挥）

```md
# Combat-N 浅层战斗·其N（难度）

- 日期 / 结果（S、通关、失败在第几块）
- 梦境描述原文要点：
- 关键敌方：数量 / 种族 / 血量感觉
- 编队：上阵了什么、推荐种族是什么
- 用的动作块：
  1. ...
  2. ...
- 卡在哪 / 哪一块最危险
- 下次要改什么（一条就够）
```

## 为什么这么短

这里只记**可复用的操作序列**。机制解释在 `../dream-mode.md`，界面长相在 `../screens.md`。
同一个事实只写一处，别抄第二遍。
