# stages —— 具体关卡记录

一个文件一关，文件名用关卡名（`combat-2.md`、`combat-3.md`）。

## 这里放什么

**只放这一关特有的东西**：编队、实际用了什么顺序、哪里卡住、结果。

机制（回合制、标记、克制）见 [../SKILL.md](../SKILL.md)，
规则见 [../rules.md](../rules.md)，键位见 [../controls.md](../controls.md)。
**同一个事实只写一处，别抄第二遍。**

## 模板

```md
# Combat-N 浅层战斗·其N（难度）

- 日期 / 结果（S / 通关 / 失败在哪一步）
- 梦境描述原文要点：
- 关键敌方：数量 / 种族
- 编队：上阵了什么、推荐种族是什么
- 实际打的顺序（简述，不用贴完整 steps）：
- 卡在哪 / 哪一步最危险
- 下次要改什么（一条就够）
```

## 什么时候写

一局打完就写，**单局经验只能进这里**。
同一条经验在**两局**里都成立，才有资格升级进 `../SKILL.md`。
