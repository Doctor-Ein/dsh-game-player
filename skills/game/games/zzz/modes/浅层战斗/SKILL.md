# 浅层战斗（梦境模式）

绝区零活动「残梦未眠之时」里的一个模式。本文回答**这个模式是什么**。

> **来源**：`[录像]` 看过 Combat-2 / Combat-3 的 3 分钟录像；
> `[实测]` 2026-11-01 亲手打通 Combat-1、Combat-2（都是 S）；
> `[小夏纠正]` 下面标了这个的，是她明确指出过我说错的。
>
> 玩法规则见 [rules.md](rules.md)，键位见 [controls.md](controls.md)，
> QTE 探针见 [qte.md](qte.md)，关卡记录见 [stages/](stages/)。

## 一局在干什么

```
活动主页 → 入梦调查 → 关卡地图（浅眠/深睡/梦潮）
        → 点关卡 → 详情页 → 入梦 → 战斗 → 挑战结果 → 回地图
```

核心循环：**打赢一关 → 解锁伙伴 → 用新伙伴打下一关**。

## 回合制：这是地基

`[小夏纠正]` **不是实时动作战斗，是回合制。**

```
第 N 轮
  我方回合：选技能 / 选目标 / 释放
  敌方回合：敌人出手
  第 N+1 轮 …
```

- 屏幕右侧有 **`第N轮`** 标记 + 竖向**行动条**，每格是一个单位（ALLY 青 / ENEMY 红）
- **轮到我方时游戏会完全停住等我**——想多久都行，敌人不会趁机动
- 我方不出手，回合就不推进，敌人也不会行动

## 标记：这个模式的骨架

游戏内「战斗引导」原文：

- **标记会提高敌人受到的伤害**
- **辅助型以骸**的技能负责给敌人**施加标记**
- **输出型以骸**的技能负责**消耗标记并追加攻击**

所以顺序是：**先上标记 → 再吃掉标记追击**，不是谁亮按谁。

**视觉特征**（`[小夏纠正]`）：

| 标记 | 长相 |
| --- | --- |
| 敌人身上有标记 | **黄色 X 型** |
| 当前选中的敌人 | **红色圆点 + 两个半圆框** |

## 技能：1 / 2 / 3 分别干什么

| 键 | 效果 | 能量 | QTE |
| --- | --- | --- | --- |
| `1` | 普通攻击 | **+30** | 无 |
| `2` | 施加标记 | −30 | **主动 QTE**（左键） |
| `3` | 消耗标记打高伤害 | −30 | **主动 QTE**，但只有**命中带标记的目标**才触发 |

能量上限 **120**。每回合只能放一个技能。

**操作方式**：按一次选中（卡片亮黄框），**再按同一个键才释放**，两次之间至少 700–850ms，太快会被吞。

## 种族克制

准备页右侧的三角：**机械 → 以骸 → 生物 → 机械**（互相克制）。

血量右侧的**蓝色箭头** = 克制生效。选关页会给「推荐：<种族>」，照着编队。

## 能量与经济

| 技能 | 能量 | 说明 |
| --- | --- | --- |
| `1` 普攻 | +30 | 攒能 |
| `2` 标记 | −30 | 上标记 + 主动 QTE |
| `3` 爆发 | −30 | 消耗标记 + 主动 QTE |

## 界面

### 活动大厅

第三人称站在外环街区，中部有 `SPECIAL EVENT` 横条，地面有金色星标任务点。

### 活动菜单（`F1`）

整屏活动主视觉，**左侧一列竖排活动名**，右下角 `前往`，右上角 `活动说明`。
左侧列表（`[录像]` 见过）：`赛博圣手，出诊！` / `迷盲境域：古堡试炼` / `式舆防卫战` /
`怪奇通屋惊魂记` / `天使应援大作战` / `台前试镜` / `拟境搜查战`。

`Esc` 退出。

### 准备页（每关都长这样）

- **认出它**：标题 `Combat-N 浅层战斗·其N` + 「简单/普通」标签，右下两个按钮（经典模式开关 + `入梦`）
- **从上到下**：
  1. `梦境描述` —— 关卡提示，直接写明了该用什么技能、敌人怕什么。**这段就是攻略**
  2. `关键敌方` —— 4 格，本关重点敌人 + 种族图标
  3. 右侧 `属性三角`
  4. `己方编队` —— 4 格，标「推荐：<种族>」
  5. `助战插件` —— 3 格，`[录像]` 里一直是空的，效果未知
  6. 底部 `通关奖励`、`经典/简易模式`开关、`入梦`

### 战斗 HUD

- 左上：血条 + 能量条
- 右上：**`第N轮`** + 竖排行动条（ALLY 青 / ENEMY 红）
- 右下：技能栏 `1` `2` `3` + `Q`
- 左下：`Q`/`E` 切换目标、`R` 看向目标、`C` 查看详情 等提示

### 挑战结果

黑底、正中大字 `挑战结果`，一条横向进度条 + 大字母评级（S/A/B），右下 `确定`。
可能弹 `获得新伙伴！`（NEW 标）。

### 模式开关

`经典模式` / `简易模式` 二选一。切简易时游戏会警告：
**选中技能后立即对默认目标释放**（省掉选目标，快但容易打错人）。

## 教程与引导

每局开头都有：先一个两页的 `战斗引导` 弹窗，关掉后是一串顶部的点击引导。
**怎么快速过 → 见 [rules.md](rules.md) 第二节。**

引导里会要求按键，例如「请按 E 切换目标到敌方巡逻者轻型」→ 按 `E`；
「2技能触发瞬时交互可添加标记」→ 实际按 `2`。
