# 绝区零 · 键位

> 状态：**部分已实测**（2026-11-01 两次实战）。标了「实测」的是真按过的；
> 没标的来自 HUD 图标，属推测，用之前先确认。

## 已实测（可信度：高）

| 动作 | 键 | 证据 |
| --- | --- | --- |
| 打开活动菜单 | `F1` | 整屏切到活动页，左侧列出七个活动模式 |
| 返回 / 关闭菜单 | `Esc` | F1 打开后按 Esc 回到大厅 |
| 移动 | `W` | 按住 600ms 角色位移明显 |
| 技能 1 / 2 / 3 | `1` `2` `3` | 按一次选中（卡片亮黄框），**再按同键才释放**，间隔 700–850ms |
| 切换目标 | `E` | 回合制战斗里切换选中的敌人 |
| 查看详情 | `C` | 战斗 HUD 提示「C 查看状态」 |
| 交互 / 对话 | `F` | 靠近 NPC 后按 F 触发对话 |
| 点击 UI | 鼠标左键 | 关卡卡片、入梦、下一页、X、结算确定，全部实测可点 |

> 前提：手必须**以管理员身份**运行，否则键鼠"发得出去、游戏没反应"（UIPI 静默丢弃）。
>
> 每次 `game_do` 前游戏必须在前台，否则报 `bound window is not foreground`。
> 从对话回到 DSH 后焦点会丢，**下一步动作前要重新聚焦**。
