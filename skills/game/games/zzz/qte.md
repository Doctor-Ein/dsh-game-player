# 绝区零 · QTE 识别（被动 QTE 为主）

> 状态：**已实现进引擎，待真机验收**（未在真实 QTE 上按过）。
> 标定台：`tools/calibrate_qte.py`；样本：`2026-10-31 08-52-20.mp4` 的 12:47–12:52。

## QTE 长什么样（实测，不是猜）

- **青色圆环 + 四角括号**，环内是灰底图标，旁边一行字「按钮亮起时点击 🖱️」
- 直径约 120px（1920 宽下，≈ 画面宽 0.062）
- **位置会跳**：12:50 在 `x≈0.68`，12:51 在画面左侧 `x≈0.23`
  → **绝对不能写固定框，必须全屏找**
- QTE 前后有强压暗（12:51 整屏亮度 36 vs 平时 148）

## 三条实测出来的坑（每条都花了时间）

### 1. 阈值必须在全分辨率做，不能先缩放

把 1920 缩到 480 再判颜色，7px 宽的亮环被平均成 1.7px 暗边，V 掉到 0.6 以下，**一个像素都检不出来**。
正确顺序：**全分辨率判阈值 → 再合并（4×4 max-pool）**。

### 2. 颜色切不掉环境

这个关卡的沙漠天空本身就是**近白青**，对照帧青色占比 7.2%，比 QTE 帧（0.25%）高 20 倍。
所以"数青色像素"在这个场景里完全无效。

### 3. 形状才是判据

| | fill（填充率） | aspect | area |
| --- | --- | --- | --- |
| QTE 环 | **0.13**（空心） | **1.18**（圆） | 117 |
| 天空块 | 0.45–0.56（实心） | 2.9–4.8（长条） | 2843–8480 |
| 角色脚下目标环 | 0.12 | 0.71 | 68（但 y≈0.88） |

再补一条 **y 带**（0.12–0.72）就能把角色脚下那个青色目标环排掉。

## 标定出的参数（将来写进 `eyes.ps1` 的 `$script:Probes`）

```
mask      H 168..196° , S ≥ 0.10 , V ≥ 0.88 , R ≥ 0.60 , G ≥ 0.90 , B ≥ 0.90
pool      全分辨率判阈值 → 4×4 合并到 480×270
shape     aspect 0.6..1.7 , fill 0.05..0.28 , area 50..800
band      cy 在 0.12..0.72
```

实测结论：QTE 帧命中 1 个环，两个对照帧 0 命中。

## 主动 QTE vs 被动 QTE（两种策略）

| | 触发 | 怎么做 |
| --- | --- | --- |
| **主动** | 我方放技能后固定时机 | **背板**：`{key 2},{wait 650},{waitfor qte,900,左键}`，识别只是保险 |
| **被动** | 敌人回合的反击 | **必须先预判敌人回合** → 开轮询 → 机械反应 |

被动 QTE 才是识别的真正价值：我们不需要看懂敌人抬手，只要能预判"下一手是敌人"，
在那一段里开着探针，剩下交给本地反射。

## 用法（接口没变）

```json
{"t":"waitfor","probe":"qte","timeoutMs":1200,
 "then":{"t":"mouse","a":"click","btn":"left"}}
```

连点型用 `then.repeat`；右键型换 `probe:"qte_right"` + `btn:"right"`。

### 实测延迟

| 段 | 耗时 |
| --- | --- |
| 采集（GDI CopyFromScreen 2560×1440） | 20.2 ms |
| 扫描（C# LockBits + 数组） | **3.9 ms** |
| 合计一次探针 | **35.6 ms** |

`waitfor` 默认 `intervalMs=40`，所以实际轮询周期 ≈ 76ms（约 13Hz）。
QTE 可见窗口实测 0.87 秒 → 窗口内能查约 11 次，够用。

### 用例

```json
{"t":"waitfor","probe":"qte","timeoutMs":1200,
 "then":{"t":"mouse","a":"click","btn":"left"}}
```

Trace 里会看到 `{"t":"waitfor","probe":"qte","hit":true/false,"waited":..,"count":..}`。
`hit:false` 是**正常结果**（那一段没出 QTE），不是错误。
