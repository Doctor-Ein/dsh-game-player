# 绝区零 · 活动「浅层战斗」（梦境模式）

来源：一段 Combat-2 / Combat-3 的实机录像（3 分钟，无语音）。
凡是这局没看到过的，一律标「未验证」，不要当事实。

## 一局在干什么

准备页配置 → **入梦** → 实时动作战斗 → 挑战结果（评级）→ 拿到新伙伴 → 回去打更深的层。
核心循环：**打赢一关 → 解锁伙伴 → 用新伙伴打下一关**。

## 战斗机制（已验证）

### 标记 —— 这个模式的骨架

游戏内「战斗引导」原文：

- **标记会提高敌人受到的伤害**
- **辅助型以骸**的部分技能负责给敌人**施加标记**
- **输出型以骸**的部分技能负责**消耗标记并追加攻击**

所以正确的顺序是：**先用辅助上标记 → 再用输出吃掉标记追击**，而不是谁亮按谁。

### 种族克制

准备页右侧的三角：**机械 → 以骸 → 生物 → 机械**。
选关页会给「推荐：<种族>」，先照着编队，打不动再换。

### 模式开关

- `经典模式` / `简易模式` 二选一。
- 切到简易模式时游戏会警告：**选中技能后立即对默认目标释放**（省掉选目标那一下，快但容易打错人）。
- 建议：先经典；手忙脚乱再切简易。

## 准备页怎么读（每关都这样）

1. 先读 `梦境描述` —— 它会直接说「敌方 X 血很厚，建议用 A 的技能；其余用 B 的群体技能」。**这段就是攻略。**
2. 看 `关键敌方` 的种族图标，对照三角。
3. `己方编队`：4 格。推荐种族优先。
4. `助战插件`：3 格，**本局一直是空的，效果未知**。
5. `入梦`。

## 结算

- 出 `挑战结果`：横向进度条 + 评级（S/A/B），右下 `继续`。
- 可能弹 `获得新伙伴！`（NEW 标），确认后入库。
- Combat-2 那局拿到的是 `离子体·纳斯安亚`，并且是 **S**。

## 打这一模式的固定套路（第一版，打完一局就改）

1. `game_shot` 确认在准备页 → 读 `梦境描述`
2. 按推荐种族进编队（先用游戏给的推荐编队，不要自己发明）
3. `入梦` → 等加载完（`game_do` 只放一个 `wait`）
4. 战斗是**回合制**（见 [turn-based.md](turn-based.md)）：我方出手 → 敌方出手，交替；**不要按实时动作来设计动作块**
5. 每块后看宫格：怪还在吗？血条动了吗？有没有弹窗？
6. 出 `挑战结果` → `game_stop` → 复盘写回本文件或 `stages/`

## 反击 QTE：已跑通的识别方式（2026-11-01 实测）

- **图标位置固定**：圆心 `(0.6922, 0.4993)`（按画面比例），半径约 `0.045 × 画面高`
- **进行中是青色**（实测 R≈118 G≈252 B≈243）；**MISS 后变灰**（R≈G≈B）
- 做法：不扫图，**在图标上布 26 个采样点**（环 20 + 中间 `>>` 6），每点带期望颜色，
  ≥80% 匹配就判定命中 → 立刻发**右键**
- 实测：单次 5.5ms，配 5ms 间隔 → **约 10ms 一个周期**
- 战果：连续两次反击 QTE 全部接住，反应落在窗口前 25%
