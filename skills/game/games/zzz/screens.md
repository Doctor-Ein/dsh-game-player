# 绝区零 · 界面识别

每个界面记三样：**叫什么、怎么一眼认出来、这里该做什么**。

## 活动准备页（浅层战斗）

- **认出它**：中间一张横版说明卡，标题是 `Combat-N 浅层战斗·其N`，右上角有「简单/普通」标签，右下角有两个按钮（经典模式开关 + `入梦`）。
- **结构（从上到下）**：
  1. `梦境描述` —— 关卡提示，写明了该用什么技能、敌人怕什么。**先读这段**。
  2. `关键敌方` —— 4 格，本关重点敌人 + 种族图标。
  3. 右侧 `属性三角`：机械 → 以骸 → 生物 → 机械（互相克制）。
  4. `己方编队` —— 4 格，上阵的以骸伙伴，旁边标「推荐：<种族>」。
  5. `助战插件` —— 3 格，独立于编队的强化槽。
  6. 底部：`通关奖励`、`经典模式 / 简易模式` 开关、`入梦`。
- **这里做什么**：先读描述 → 按推荐种族编队 → `入梦`。

## 战斗 HUD

- **认出它**：左上一条长血条 + 能量条；右上竖排小地图 + 队伍；右下角一排技能按钮；屏幕中下方是敌人血条。
- **读什么**：
  - 左上 `XXXX/XXXX` 是自己的血
  - 右上 `第1轮` + 竖排头像 = 轮次与名单
  - 右侧中部一列小图标 = 当前 buff
  - 左下角会有 `【区域名】` 和 `波次 1/1`

## 挑战结果

- **认出它**：黑底、正中大字 `挑战结果`，一条横向进度条 + 大字母评级（S/A/B），右下 `继续`。
- **这里做什么**：看评级和进度条 → `继续` → 可能弹「获得新伙伴！」（带 NEW 标）→ 确认。

## 活动大厅（SPECIAL EVENT）

- **认出它**：第三人称视角站在外环街区，屏幕中部有 `SPECIAL EVENT` 横条，地面有金色星标任务点。
- **这里做什么**：走向星标触发剧情 → 进准备页。

## 活动菜单（`F1` 打开）

- **认出它**：整屏换成一张巨大的活动主视觉，**左侧一列竖排活动名**，右下角 `前往`，右上角有 `活动说明` 和剩余天数。
- **左侧列表（实测见到的，从上到下）**：
  `赛博圣手，出诊！` / `迷盲境域：古堡试炼` / `式舆防卫战` / `怪奇通屋惊魂记` / `天使应援大作战` / `台前试镜` / `拟境搜查战`
- 底部还有 `限时奖励` 和 `邦布维修进度 4/5`。
- **这里做什么**：选中活动 → `前往`（`Enter` 确认）。要进「浅层战斗」就先点对应的活动。
- **怎么退**：`Esc` 回大厅。
