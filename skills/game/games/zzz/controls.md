## HUD 上看到的（可信度：中）

截图右下角有一排带字母的圆形按钮，能认出：

| 图标位置 | 字母 | 猜测 |
| --- | --- | --- |
| 右下最右 | `Space` | 闪避 / 特殊动作 |
| 右下 | `E` | 技能 |
| 右下 | `Q` | 终结技（通常需要能量满） |
| 右下 | `C` | 切人 |
| 右下 | `R` | 支援 / 交互 |
| 左下 | `L`、`Tab` | 地图 / 快速轮盘 |

## 实测过的（可信度：高）

| 动作 | 键 | 证据 |
| --- | --- | --- |
| 打开活动菜单 | `F1` | 提权后实测：整屏切到「赛博圣手，出诊！」活动页，左侧列出七个活动模式 |
| 返回 / 关闭菜单 | `Esc` | F1 打开后按 Esc 回到大厅 |
| 移动 | `W` | 按住 600ms 角色位移明显 |

> 前提：手必须**以管理员身份**运行，否则这三个都"发得出去、游戏没反应"（UIPI 丢弃）。
