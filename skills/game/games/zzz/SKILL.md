这一层**只做导航**。具体知识按「模式」组织在 `modes/` 下。

## 模式

| 模式 | 入口 | 状态 |
| --- | --- | --- |
| 浅层战斗（活动「残梦未眠之时」） | [modes/浅层战斗/](modes/浅层战斗/SKILL.md) | Combat-1、Combat-2 已通关（S） |

## 开一个新模式时

建 `modes/<模式名>/`，里面通常是：

| 文件 | 放什么 |
| --- | --- |
| `SKILL.md` | **这个模式是什么**：一局流程、机制、界面 |
| `rules.md` | 小夏定的规则 + 操作技巧 |
| `controls.md` | 键位（这个模式专属的） |
| `qte.md` | QTE 探针（用得到才建） |
| `stages/` | 一关一个文件 |

## 通用约定

写知识前先读 [../../learning.md](../../learning.md)：

- 每条标来源：`[实测]` / `[录像]` / `[小夏纠正]` / `[推测]`
- **一个事实只写一处**，别处引用
- 单局经验只进 `stages/`，两局都成立才升级
