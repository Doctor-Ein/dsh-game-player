# 绝区零「浅层战斗」的基础：这是回合制

> 这是整个模式的地基。不理解这条，后面所有"预判"都是错的。
> 记录于 2026-11-01，小夏纠正。

## 一句话

**不是实时动作战斗，是回合制。** 我方行动 → 敌方行动 → 我方行动，交替进行。

## 回合怎么走

```
第 N 轮
  我方回合：选技能 / 选目标 / 释放
  敌方回合：敌人出手，可能是普通攻击，也可能是特定技能
  第 N+1 轮 …
```

- 屏幕右侧有 **`第N轮`** 标记 + 竖向的**行动条**
- 行动条里每一格是一个单位（我方 / 敌方），高亮在哪一格就说明轮到谁
- **轮到自己出手时，不需要盯任何 QTE**

## QTE 出现的条件（关键）

| QTE | 触发条件 | 按键 |
| --- | --- | --- |
| **主动 QTE** | **我方**释放特定技能（例：提尔锋的 `2` 技能） | 左键，且要等圈收缩到位 |
| **反击 QTE** | **敌方**在它自己的回合使用**特定技能**（这里敌人也是提尔锋，用的是 `1` 技能） | 右键，出现即可按 |

所以：

- **敌人普通攻击不会触发反击窗口**，只有它放那个特定技能才会
- 站着挨打没用——**敌人得轮到出手、而且得用对技能**
- 我方不出手时，敌人不会行动（回合没推进）

## 这一条推翻的错误做法

| 错误做法 | 为什么错 |
| --- | --- |
| 全程连续守卫 30 秒 | 大部分时间根本不是敌人的回合，守了也白守 |
| 站着不动让敌人打 | 回合没推进，敌人不会出手 |
| 把 QTE 当成"随时可能出现" | 它只在两个明确时机出现：我方放特定技能后 / 敌方用特定技能时 |
| 用"实际战斗"的节奏设计窗口 | 回合制的窗口在**行动结算**里，不在帧循环里 |

## 正确的预判方式

1. **我方回合**：我要放什么技能？如果放的是会触发主动 QTE 的技能 → 放完立刻开窗（左键，等收缩）
2. **敌方回合**：敌人出手前/出手时开窗（右键，出现就打）
3. 因此窗口应该**跟着回合走**：`我方行动 → 敌方行动 → …`，而不是一条长守卫

## 还没确认的

- 行动条具体怎么读（几格、高亮框长什么样）——需要一次专门观察
- 敌方用哪个技能会触发反击，是否固定为 `1`
- 我方哪些技能会触发主动 QTE
