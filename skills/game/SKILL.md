## 目录组织

```
games/<游戏>/
├── SKILL.md              只做导航
└── modes/<模式>/          一个活动模式一个目录
    ├── SKILL.md           这个模式是什么（流程、机制、界面）
    ├── rules.md           规则 + 操作技巧
    ├── controls.md        键位
    ├── qte.md             QTE 探针
    └── stages/            一关一个文件
```

**知识按模式分，不跨模式混。** 换一个活动模式就新建一个目录。

## 定位入口

连接后有四个操作工具：game_shot / game_find / game_do / game_stop。小按钮先用 game_find 给出 center，再填入 click；不要从缩放宫格估计坐标。截图/模板 region 是客户区物理像素，网格/center/鼠标 x/y 是屏幕物理像素，允许副屏负坐标。QTE 仍用 game_do 的 waitfor，不改成反复调用 game_find。

升级后重新加载插件、重开手并重新连接，确认引擎 v2。停止或换手后也要重新连接。

## 硬规则（任何游戏都不变）

0. **手必须是管理员权限。** 游戏若以管理员运行，Windows 的 UIPI 会**静默丢弃**低权限进程发来的键鼠——表现是"按下去了、游戏没反应"。启动器会自己弹 UAC。
1. **没有连上手就不动手。** 工具不在 = 没敲 `/game`。
2. **一次动作块 ≤ 5 秒游戏时间。** 长了必然失控。
3. **不写长按几十秒的宏。** 像人比像机器重要。
4. **F12 是唯一急停。** 停不下来就喊人，不要连按。
5. **知识写在文件里才算学会。** 记住的对话会丢，文件不会。
6. **截图只是屏幕像素。** 被别的窗口盖住的部分，看到的就是遮挡物；ZZZ 不支持 `PrintWindow`（已验证），绕不过去。
