# QTE 识别与触发（技术说明）

> 给以后接手的人（包括我自己）看：这套东西**为什么长这样**，参数从哪来。
> 版本 0.1.0，2026-11-01 实测通过。

## 一、这个游戏里 QTE 的两种

| | 反击 QTE | 主动 QTE |
| --- | --- | --- |
| 触发 | **敌方**回合使用特定技能 | **我方**释放特定技能（如提尔锋 `2`） |
| 图标 | 青色环 + `>>` + 「快速点击」 | 青色环 + 拳头 + 「按钮亮起时点击」 |
| 按键 | **右键** | **左键** |
| 时机 | 出现即可按 | 要等内圈收缩到合适范围 |

**关键前提：这是回合制。** 我方行动完才轮到敌方，敌方普通攻击不触发反击窗口。
所以窗口是"跟回合走"的，不是随时都可能出现。

## 二、识别：两段式

### 第 1 阶段 — 有没有 QTE

在图标上布一组**固定采样点**，每个点带期望 RGB，逐点比对：

```
三通道差之和 ≤ 70  →  这个点算匹配
匹配点数 / 总点数 ≥ 阈值  →  命中
```

| 探针 | 环上点 | 内部点 | 阈值 |
| --- | --- | --- | --- |
| 反击 | 20 个（半径 0.0451×H） | 6 个（`>>`） | 0.80 |
| 主动 | 12 个（半径 0.0375×H） | 9 个（拳头轮廓） | 0.80 |

**为什么要 20 个环点**：环是青色、场景里青色不罕见，单点会误判；均匀分布 20 个点等于在验证"这里有个圆"。

### 第 2 阶段 — 是哪一种

只看**内圈字形**（外圈辉光/倒计时都不看），因为它才是形状的本质：

```
① 以图标中心为心，裁半径 0.0235×H 的方框
② 面积平均缩到 48×48 灰度
③ 和模板算归一化互相关（NCC），位置 ±2px 搜索
④ NCC ≥ 0.70 才算"像"
```

**实测分离度**：

| | 反击模板 | 主动模板 |
| --- | --- | --- |
| 反击截图 | **0.98** | 0.03 |
| 主动截图 | 0.26 | **0.99** |

这就是为什么"反击模板套在主动图标上图案能中 0.96"却不触发——字形那一关把它拦下了。

**加新 QTE 类型**：`tools/gen_glyph_tpl.py` 生成一张 48×48 模板 + 加一个探针，代码不用动。

## 三、触发：守卫模式 + 多探针并行

```json
{"t":"waitfor","holdMs":60000,"intervalMs":5,
 "probes":[
   {"probe":"qte_counterattack","gapMs":150,"then":{"t":"mouse","a":"click","btn":"right"}},
   {"probe":"qte_flag",        "gapMs":150,"then":{"t":"mouse","a":"click","btn":"left"}}
 ]}
```

- `holdMs`：守多久（到点自动停）
- `intervalMs`：轮询间隔，最小 5ms
- `gapMs`：同一探针两次开火的间隔，防连打
- 每条 `waitfor` 在 trace 里各占一行，带 `fires=[...]` 时刻表

**为什么必须并行**：反击会连着出两个，顺序等待时中间那段时间是盲区。

## 四、性能账

| 环节 | 耗时 |
| --- | --- |
| 截图（CopyFromScreen，238×238） | ~5.0ms |
| 26 个采样点 | ~0.05ms |
| 48×48 NCC ×（25 位置） | ~1.2ms |
| **单探针合计** | **6.75ms** |
| 双探针 + 5ms 间隔 | **约 19ms/周期** |

QTE 窗口约 0.5 秒 → 一个窗口能查 26 次。

## 五、怎么重新生成模板

```powershell
cd packages\dsh-game-player\tools
# 采样点模板（需要两种图标的新截图）
python gen_pattern2.py qte-real.jpg    > 反击采样点
python gen_flag.py     qte-flag.png    > 主动采样点
# 字形模板（48x48 灰度）
python gen_glyph_tpl.py                > tpl3-counter.png / tpl3-flag.png
```

改完模板要**重启手**（`start-gameplay.cmd`）。

## 六、别踩的坑

- **不要用录像验证检测器**：1080p 缩放+压缩后峰值只有 0.62，会误判成"检测失效"
- **不要超过 110 秒**：`game_do` 有 120 秒上限，超了 trace 全丢
- **不要先截图再按键**：先 `look` 再点击会白扔 200ms，反击直接接不住
- **不要用"排除规则"**区分类型：新类型一多就写不动，用"像不像我"的模板
