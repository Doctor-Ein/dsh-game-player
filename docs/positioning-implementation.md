# 定位实现方案与验收

日期：2026-11-01；版本：0.2.0；仅修改 dsh-game-player package。

DSH 侧工具签名、返回格式和兼容性迁移见 [接口交接](interfaces-v2.md)。

## 目标与边界

模型识别界面、选择目标；工具给出坐标。新增一个 `game_find`，复用既有 `game_shot` 和 `game_do`，不增加动作类型，不把识图或策略塞进本地 QTE 反射。OCR 留待后续有明确读取场景时再做。

本次定位需求允许命名裁片模板，是对旧 SCOPE 中「4 个工具/不做模板」的局部扩展。不会引入 OpenCV、战斗策略、自动点击或常驻视觉监控。

## 对原始文档的两点校正

1. 绝对输入只有同时带 `MOUSEEVENTF_VIRTUALDESK` 才映射整个虚拟桌面；没有它时映射主屏。仅替换分母会制造错误。[微软 MOUSEINPUT 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-mouseinput)。
2. GetClientRect 并非无条件返回需要乘 DPI 的数值。本实现让执行线程进入 per-monitor DPI aware，上下游直接使用物理像素，**不再额外乘 DPI/96**，防止重复缩放。[微软 DPI 文档](https://learn.microsoft.com/en-us/windows/win32/hidpi/high-dpi-desktop-application-development-on-windows)。

每条引擎请求重设/验证线程 DPI 上下文，避免 PowerShell 线程或宿主默认 DPI 设置造成口径漂移。Windows 10 1607+ 为最低要求。

## 一条明确的坐标链

| 数据 | 单位与原点 |
| --- | --- |
| 截图/搜索/录制 region | 客户区物理像素，以客户区左上为原点 |
| 原图 source、网格、匹配 bounds/center | 虚拟桌面屏幕物理像素，允许负数 |
| 鼠标 abs / click x/y | 与匹配 center 相同，可直接传递 |
| 预览/宫格像素 | 仅显示用途；预览附 source 与实际 scaleX/scaleY |

裁剪按矩形交集计算；不会把负坐标变成零，也不会在屏外硬造最小宽度。窗口矩形由手在请求时查，窗口移动/缩放之后自动更新。虚拟桌面范围每次读 Windows，因此显示器热插拔后不使用旧范围。显示器矩形之间的空洞拒绝作为鼠标目标。

SendInput 使用 `MOVE | ABSOLUTE | VIRTUALDESK`。归一化瞄准像素中心：`floor((point-origin+0.5)*65536/size)`，裁到 65535，避免第一/最后像素和边界的取整偏差；不使用 SetCursorPos 作为静默兜底。

## 模板生命周期

`game_shot` 一次采集，先存未缩放原图，再生成预览/网格。进程索引保存最近 16 个 shotId 和客户区/屏幕原点；从已返回的那一帧录制，避免看到的状态和实际录制的状态不同。`record.region` 在这张图的客户区坐标下解释，并必须完整落在已采集区域内。

`game_find({template,record:{shotId,region}})` 录制命名 PNG，返回裁片供检查，拒绝覆盖已有名字。`game_find({template,region?,threshold?,maxResults?})` 搜索新帧并返回按 score 排序、抑制重叠后的多个精确目标。不会自动点击。无结果时返回空数组。

匹配采用无依赖 C# 全像素位置扫描，RGB 的归一化均方根误差，逐项误差超过预算即提前淘汰。没有缩小搜索图、跳过像素或只保留粗匹配候选，因此不会因采样步长漏掉像素位置。高辨识度模板像素优先比较。相比 NCC，它对颜色/亮度变化更敏感，但含义简单，阈值 1 可要求像素完全一致。阈值不是置信度；`.9` 表示 RGB RMSE 不超过 25.5。

限制为每边 3–512px；拒绝低纹理模板；搜索图最多 1600 万像素，15 秒超时；匹配过于密集时提示收窄区域/提高辨识度，避免无限积累候选。模板不自动适应缩放/旋转/透明度，分辨率或 UI 状态变化时需重录。

## 连接可靠性与输入证据

名片 PID、连接 hello PID、引擎版本、坐标口径及源码 SHA-256 必须一致，宿主才 armed。源码指纹覆盖引擎各文件、匹配器和手入口，不依赖进程名或编译日志猜测。管道换连接时立即清空旧 hello、拒绝旧请求；断线/更换 PID 后操作工具要求重新 attach。正常连接中断时手松开输入；等待连接时不反复发松键事件。

自测不发布/删除运行中的 hand.json；退出时只移除属于自己的名片。SendInput 检查返回值。点击 x/y 先移动，失败则停止块，避免后续点击打到旧位置。game_stop 先停用工具，松手失败不会报告成功。F12 覆盖反射 hold/gap/wait；检测器和采样点保持原样。
